Project Overview

Welcome to my digital species dossier collection. This project highlights four distinct species found at the Fresno Chaffee Zoo, categorized by their scientific class.

Please use the navigation menu above to explore the detailed fact sheets for each animal. Each report includes formal scientific classifications, physical profiles, geographical maps, and behavioral ecology.
